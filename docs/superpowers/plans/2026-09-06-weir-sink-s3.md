# weir-sink-s3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `weir-sink-s3` — a separately published S3-API sink crate — plus the `weir-sink-sdk` and `weir-server` changes that let a weir daemon archive records to S3, MinIO, R2 or B2 with replay-stable object keys.

**Architecture:** A new workspace crate implements `weir_sink_sdk::Sink` over hand-rolled SigV4 on the `reqwest`/`sha2`/`hmac` stack already in the tree. Four of its six modules are pure functions (signing, key construction, body framing, civil-date conversion) so the hard-to-verify parts are exhaustively unit-testable offline; only credentials and the HTTP client touch the network. Object keys combine a time partition derived from the **WAB segment header's `created_at`** with a filename derived from the batch's `DedupToken`, making both halves invariant under crash-replay.

**Tech Stack:** Rust 2024 (MSRV 1.88), `reqwest` (rustls/ring), `sha2`, `hmac`, `zstd`, `tokio`, `thiserror`, `tracing`. MinIO + docker-compose for integration tests.

**Spec:** [`docs/superpowers/specs/2026-09-06-s3-sink-design.md`](../specs/2026-09-06-s3-sink-design.md)

## Global Constraints

- **Crypto provider is `ring`, workspace-wide.** `cargo tree` must show **no `aws-lc-sys`** and **exactly one `rustls` version**. Any dependency that pulls `aws-lc-rs` is rejected.
- **Exactly one new third-party crate is permitted: `hmac`.** Everything else must already be in `weir-server`'s tree. In particular **no date/time crate** — `time` is a *dev*-dependency only (via `rcgen` in `weir-testkit`), so UTC conversion is hand-rolled in `time.rs` (Task 4).
- **No commit trailers.** This repo uses none — verified against `git log`. Do not add `Co-Authored-By` or `Claude-Session` lines.
- **Every commit passes the gate:** `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, and the tests named in the task.
- **Commit message style:** subject line states the defect or deliverable in plain words; body explains *why*, names the tests watched failing first, and ends with a `Gate:` line listing the commands run and their results. Match the surrounding `git log`.
- **`#![deny(missing_docs)]`** on the new crate — it is published, and every other published weir crate does this.
- **Public surface stays minimal:** only `S3Sink`, `S3SinkConfig`, `S3SinkError`, and the config enums are `pub`. Everything else is `pub(crate)`.
- **Base branch:** this work must sit on a `main` that already contains `fix/sweep-truth-up` (see Task 0). The `403 → Degraded` health mapping is unsafe without `ae392bc`.

```rust
//! Unix-nanosecond → UTC calendar-field conversion.
//!
//! Hand-rolled because the workspace has no date library in its production
//! dependency tree (`time` is a dev-dependency via `rcgen`) and this crate's
//! dependency budget is spent on `hmac`. The algorithm is Howard Hinnant's
//! `civil_from_days`, which is public domain and exact for the proleptic
//! Gregorian calendar over the whole `i64` range this crate can see.

/// UTC calendar fields for an instant.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) struct Utc {
    pub(crate) year: i64,
    pub(crate) month: u32,
    pub(crate) day: u32,
    pub(crate) hour: u32,
    pub(crate) minute: u32,
    pub(crate) second: u32,
}

/// Days since 1970-01-01 → `(year, month, day)`.
///
/// Howard Hinnant, "chrono-Compatible Low-Level Date Algorithms".
fn civil_from_days(z: i64) -> (i64, u32, u32) {
    let z = z + 719_468;
    let era = if z >= 0 { z } else { z - 146_096 } / 146_097;
    let doe = (z - era * 146_097) as u64; // [0, 146096]
    let yoe = (doe - doe / 1460 + doe / 36_524 - doe / 146_096) / 365; // [0, 399]
    let y = yoe as i64 + era * 400;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100); // [0, 365]
    let mp = (5 * doy + 2) / 153; // [0, 11]
    let d = (doy - (153 * mp + 2) / 5 + 1) as u32; // [1, 31]
    let m = if mp < 10 { mp + 3 } else { mp - 9 } as u32; // [1, 12]
    (if m <= 2 { y + 1 } else { y }, m, d)
}

/// Converts unix nanoseconds to UTC calendar fields.
///
/// Uses Euclidean division so pre-epoch (negative) instants floor rather than
/// truncate toward zero — truncation would place 1969-12-31T23:59:59Z on
/// 1970-01-01.
pub(crate) fn utc_from_unix_nanos(nanos: i64) -> Utc {
    let secs = nanos.div_euclid(1_000_000_000);
    let days = secs.div_euclid(86_400);
    let sod = secs.rem_euclid(86_400);
    let (year, month, day) = civil_from_days(days);
    Utc {
        year,
        month,
        day,
        hour: (sod / 3_600) as u32,
        minute: ((sod % 3_600) / 60) as u32,
        second: (sod % 60) as u32,
    }
}
```

```rust
//! Object key construction.
//!
//! # Why the key is shaped this way
//!
//! weir's drain is at-least-once: after a crash it re-commits a byte-identical
//! batch. A key containing wall-clock would place that replay under a *new*
//! partition path, so the bucket would hold two objects with identical content
//! and every query would count the records twice.
//!
//! Both halves of the key are therefore replay-invariant:
//!
//! - the **partition path** comes from the owning WAB segment's `created_at`,
//!   which is written once into the segment header and read back unchanged;
//! - the **filename** is the batch's `DedupToken`, a hash of its contents.
//!
//! A replayed batch therefore overwrites its own object with identical bytes.
//!
//! The rendering is always **UTC**. Local time would make the key depend on the
//! host's `TZ`, reintroducing the same duplication across a DST change.

use crate::time::{Utc, utc_from_unix_nanos};

/// Why a partition template was rejected.
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) enum TemplateError {
    /// A `%X` where `X` is not one of `Y`, `m`, `d`, `H`.
    UnknownSpecifier(char),
    /// The template ended with a bare `%`.
    TrailingPercent,
    /// The template contained a `..` path segment.
    ParentSegment,
}

impl std::fmt::Display for TemplateError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::UnknownSpecifier(c) => write!(
                f,
                "unknown partition specifier '%{c}'; only %Y, %m, %d and %H are supported"
            ),
            Self::TrailingPercent => write!(f, "partition template ends with a bare '%'"),
            Self::ParentSegment => write!(f, "partition template may not contain a '..' segment"),
        }
    }
}

impl std::error::Error for TemplateError {}

/// One piece of a parsed partition template.
#[derive(Debug, Clone, PartialEq, Eq)]
enum Piece {
    Literal(String),
    Year,
    Month,
    Day,
    Hour,
}

/// A validated partition template.
///
/// The syntax is deliberately tiny — `%Y`, `%m`, `%d`, `%H`, everything else
/// literal. It is **not** strftime: a full implementation would admit `%s` and
/// other wall-clock-shaped specifiers that defeat the replay-stability the key
/// scheme exists to provide.
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct PartitionTemplate {
    pieces: Vec<Piece>,
}

impl PartitionTemplate {
    /// Parses a template, rejecting unknown specifiers rather than passing
    /// them through.
    pub(crate) fn parse(s: &str) -> Result<Self, TemplateError> {
        if s.split('/').any(|seg| seg == "..") {
            return Err(TemplateError::ParentSegment);
        }
        let mut pieces = Vec::new();
        let mut literal = String::new();
        let mut chars = s.chars();
        while let Some(c) = chars.next() {
            if c != '%' {
                literal.push(c);
                continue;
            }
            let Some(spec) = chars.next() else {
                return Err(TemplateError::TrailingPercent);
            };
            let piece = match spec {
                'Y' => Piece::Year,
                'm' => Piece::Month,
                'd' => Piece::Day,
                'H' => Piece::Hour,
                other => return Err(TemplateError::UnknownSpecifier(other)),
            };
            if !literal.is_empty() {
                pieces.push(Piece::Literal(std::mem::take(&mut literal)));
            }
            pieces.push(piece);
        }
        if !literal.is_empty() {
            pieces.push(Piece::Literal(literal));
        }
        Ok(Self { pieces })
    }

    /// Renders the template for an instant. Always UTC.
    pub(crate) fn render(&self, t: Utc) -> String {
        let mut out = String::new();
        for piece in &self.pieces {
            match piece {
                Piece::Literal(s) => out.push_str(s),
                Piece::Year => out.push_str(&format!("{:04}", t.year)),
                Piece::Month => out.push_str(&format!("{:02}", t.month)),
                Piece::Day => out.push_str(&format!("{:02}", t.day)),
                Piece::Hour => out.push_str(&format!("{:02}", t.hour)),
            }
        }
        out
    }

    /// True when the template renders nothing (partitioning disabled).
    pub(crate) fn is_empty(&self) -> bool {
        self.pieces.is_empty()
    }
}

/// Builds the full object key.
///
/// `created_at` is the owning segment's creation time in unix nanoseconds;
/// `token_hex` is the batch's `DedupToken` as lowercase hex; `ext` is the
/// framing plus compression suffix (e.g. `ndjson.zst`), without a leading dot.
pub(crate) fn object_key(
    prefix: &str,
    tmpl: &PartitionTemplate,
    created_at: i64,
    token_hex: &str,
    ext: &str,
) -> String {
    let mut parts: Vec<String> = Vec::new();
    let prefix = prefix.trim_matches('/');
    if !prefix.is_empty() {
        parts.push(prefix.to_string());
    }
    if !tmpl.is_empty() {
        let rendered = tmpl.render(utc_from_unix_nanos(created_at));
        let rendered = rendered.trim_matches('/');
        if !rendered.is_empty() {
            parts.push(rendered.to_string());
        }
    }
    parts.push(format!("{token_hex}.{ext}"));
    parts.join("/")
}
```

```rust
//! AWS Signature Version 4, header-based, for S3 requests.
//!
//! Hand-rolled rather than taken from `aws-sdk-s3`: the official SDK adds 68
//! crates to weir-server's tree and, at default features, pulls `aws-lc-sys`
//! plus a second `rustls` — against a workspace that deliberately unified on
//! `ring`. Correctness is bought back with AWS's own published test vectors
//! (`tests/sigv4_vectors.rs`) rather than with trust.
//!
//! Scope: SigV4 only (no SigV4a), header-based only (no presigned URLs), and
//! the payload hash is always computed — `UNSIGNED-PAYLOAD` is not used,
//! because providers differ in what they accept and the body is already in
//! memory.

use hmac::{Hmac, Mac};
use sha2::{Digest, Sha256};

use crate::time::utc_from_unix_nanos;

type HmacSha256 = Hmac<Sha256>;

const ALGORITHM: &str = "AWS4-HMAC-SHA256";

/// Everything needed to sign one request.
pub(crate) struct SigningParams<'a> {
    /// Uppercase HTTP method.
    pub(crate) method: &'a str,
    /// Absolute path, already percent-encoded, with a leading `/`.
    pub(crate) uri_path: &'a str,
    /// Canonical query string (sorted, encoded). Empty when there is none.
    pub(crate) query: &'a str,
    /// Headers to sign. Must include `host`. Names in any case; normalised here.
    pub(crate) headers: &'a [(String, String)],
    /// Request body.
    pub(crate) payload: &'a [u8],
    pub(crate) access_key_id: &'a str,
    pub(crate) secret_access_key: &'a str,
    pub(crate) session_token: Option<&'a str>,
    pub(crate) region: &'a str,
    /// `"s3"` in production; the AWS test suite uses `"service"`.
    pub(crate) service: &'a str,
    /// Signing instant, unix nanoseconds.
    pub(crate) timestamp_nanos: i64,
}

/// The signing outputs a caller attaches to the request.
pub(crate) struct Signed {
    pub(crate) authorization: String,
    pub(crate) amz_date: String,
    pub(crate) content_sha256: String,
}

fn hex(bytes: impl AsRef<[u8]>) -> String {
    bytes.as_ref().iter().map(|b| format!("{b:02x}")).collect()
}

fn sha256_hex(data: &[u8]) -> String {
    hex(Sha256::digest(data))
}

fn hmac(key: &[u8], data: &[u8]) -> Vec<u8> {
    let mut mac = HmacSha256::new_from_slice(key).expect("HMAC accepts any key length");
    mac.update(data);
    mac.finalize().into_bytes().to_vec()
}

/// `YYYYMMDD'T'HHMMSS'Z'`.
fn amz_date(nanos: i64) -> String {
    let t = utc_from_unix_nanos(nanos);
    format!(
        "{:04}{:02}{:02}T{:02}{:02}{:02}Z",
        t.year, t.month, t.day, t.hour, t.minute, t.second
    )
}

/// Headers lowercased, values whitespace-trimmed, sorted by name.
fn normalised_headers(headers: &[(String, String)]) -> Vec<(String, String)> {
    let mut h: Vec<(String, String)> = headers
        .iter()
        .map(|(k, v)| (k.to_ascii_lowercase(), v.trim().to_string()))
        .collect();
    h.sort_by(|a, b| a.0.cmp(&b.0));
    h
}

/// `;`-joined lowercase header names, sorted.
fn signed_headers(headers: &[(String, String)]) -> String {
    normalised_headers(headers)
        .iter()
        .map(|(k, _)| k.as_str())
        .collect::<Vec<_>>()
        .join(";")
}

/// The SigV4 canonical request.
pub(crate) fn canonical_request(p: &SigningParams<'_>) -> String {
    let headers = normalised_headers(p.headers);
    let canonical_headers: String = headers
        .iter()
        .map(|(k, v)| format!("{k}:{v}\n"))
        .collect();
    format!(
        "{}\n{}\n{}\n{}\n{}\n{}",
        p.method,
        p.uri_path,
        p.query,
        canonical_headers,
        signed_headers(p.headers),
        sha256_hex(p.payload),
    )
}

/// `<date>/<region>/<service>/aws4_request`.
fn credential_scope(p: &SigningParams<'_>) -> String {
    let d = &amz_date(p.timestamp_nanos)[..8];
    format!("{d}/{}/{}/aws4_request", p.region, p.service)
}

/// The SigV4 string-to-sign, given an already-built canonical request.
pub(crate) fn string_to_sign(p: &SigningParams<'_>, canonical: &str) -> String {
    format!(
        "{ALGORITHM}\n{}\n{}\n{}",
        amz_date(p.timestamp_nanos),
        credential_scope(p),
        sha256_hex(canonical.as_bytes()),
    )
}

/// `kDate → kRegion → kService → kSigning`.
fn signing_key(p: &SigningParams<'_>) -> Vec<u8> {
    let d = &amz_date(p.timestamp_nanos)[..8];
    let k_date = hmac(format!("AWS4{}", p.secret_access_key).as_bytes(), d.as_bytes());
    let k_region = hmac(&k_date, p.region.as_bytes());
    let k_service = hmac(&k_region, p.service.as_bytes());
    hmac(&k_service, b"aws4_request")
}

/// Signs a request, returning the headers to attach.
pub(crate) fn sign(p: &SigningParams<'_>) -> Signed {
    let canonical = canonical_request(p);
    let sts = string_to_sign(p, &canonical);
    let signature = hex(hmac(&signing_key(p), sts.as_bytes()));
    Signed {
        authorization: format!(
            "{ALGORITHM} Credential={}/{}, SignedHeaders={}, Signature={signature}",
            p.access_key_id,
            credential_scope(p),
            signed_headers(p.headers),
        ),
        amz_date: amz_date(p.timestamp_nanos),
        content_sha256: sha256_hex(p.payload),
    }
}
```

```rust
//! Turning a commit batch into an object body.
//!
//! # Why NDJSON is the default
//!
//! The point of an object-store archive is that Athena, DuckDB, Spark and Glue
//! can read the bucket directly. Newline-delimited records are what those
//! engines expect; a weir-specific container would forfeit the main reason to
//! write to object storage at all.
//!
//! A record containing a newline cannot be represented in that framing. It is
//! dead-lettered rather than written, exactly as the HTTP sink's NDJSON mode
//! already does — writing it anyway would split one record into two lines
//! downstream, which is a silent corruption of the data's shape. Operators with
//! such payloads use [`Framing::LengthPrefixed`].

use weir_core::Payload;

/// How records are laid out inside one object.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Framing {
    /// Newline-delimited records. Readable by every common query engine.
    /// Records containing `\n` or `\r` are dead-lettered.
    #[default]
    Ndjson,
    /// `u64` little-endian length prefix per record. Binary-safe; needs a
    /// weir-aware reader. File extension `weirbin`.
    LengthPrefixed,
}

/// Object body compression.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Compression {
    /// Store uncompressed.
    None,
    /// zstd. Already in weir's tree for WAB format v2; read by Athena and Spark.
    #[default]
    Zstd,
}

/// A framed batch: the bytes to upload, plus the partition of the input.
pub(crate) struct Framed {
    pub(crate) body: Vec<u8>,
    pub(crate) committed: Vec<Payload>,
    pub(crate) dead_lettered: Vec<(Payload, String)>,
}

/// Frames and compresses a batch.
pub(crate) fn frame(
    records: Vec<Payload>,
    framing: Framing,
    compression: Compression,
) -> Framed {
    let mut raw = Vec::new();
    let mut committed = Vec::new();
    let mut dead_lettered = Vec::new();

    for record in records {
        match framing {
            Framing::Ndjson => {
                if record.as_ref().iter().any(|b| *b == b'\n' || *b == b'\r') {
                    dead_lettered.push((
                        record,
                        "record contains a newline; NDJSON framing cannot represent it \
                         (use sink_s3_framing = \"length-prefixed\" for binary payloads)"
                            .to_string(),
                    ));
                    continue;
                }
                raw.extend_from_slice(record.as_ref());
                raw.push(b'\n');
            }
            Framing::LengthPrefixed => {
                raw.extend_from_slice(&(record.as_ref().len() as u64).to_le_bytes());
                raw.extend_from_slice(record.as_ref());
            }
        }
        committed.push(record);
    }

    let body = if raw.is_empty() {
        // Every record was dead-lettered. Return empty so the caller skips the
        // upload — an empty object is pure noise in the bucket.
        Vec::new()
    } else {
        match compression {
            Compression::None => raw,
            Compression::Zstd => {
                zstd::encode_all(&raw[..], 3).expect("zstd encoding of an in-memory buffer")
            }
        }
    };

    Framed { body, committed, dead_lettered }
}

/// File extension for a framing/compression pair, without a leading dot.
pub(crate) fn extension(framing: Framing, compression: Compression) -> String {
    let base = match framing {
        Framing::Ndjson => "ndjson",
        // Deliberately not `bin`: the framing is weir-specific and the name
        // should say so rather than imply a format a reader might guess wrong.
        Framing::LengthPrefixed => "weirbin",
    };
    match compression {
        Compression::None => base.to_string(),
        Compression::Zstd => format!("{base}.zst"),
    }
}

/// HTTP `Content-Type` for a framing.
pub(crate) fn content_type(framing: Framing) -> &'static str {
    match framing {
        Framing::Ndjson => "application/x-ndjson",
        Framing::LengthPrefixed => "application/octet-stream",
    }
}
```

```rust
/// Whether a failed request should be retried or dead-lettered.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum Classification {
    /// Retry the segment.
    Transient,
    /// Dead-letter the batch.
    Permanent,
}

/// Classifies an S3 error response.
///
/// Mirrors `weir-server`'s `sink/clickhouse.rs::status_is_transient`, with two
/// S3-specific departures documented at their arms.
pub(crate) fn classify(status: u16, s3_code: Option<&str>) -> Classification {
    // The one 403 that is not an authorisation decision. A drifted clock may
    // resync; dead-lettering a backlog over NTP drift is the wrong trade.
    if s3_code == Some("RequestTimeTooSkewed") {
        return Classification::Transient;
    }
    match status {
        500..=599 | 408 | 429 => Classification::Transient,
        400 | 401 | 403 | 404 | 405 | 411 | 413 => Classification::Permanent,
        // Providers diverge (R2, B2, Ceph, MinIO). An unrecognised response
        // strands rather than dead-letters: a stranded segment is recoverable
        // by an operator, a dead-lettered one needs a requeue.
        _ => Classification::Transient,
    }
}
```
