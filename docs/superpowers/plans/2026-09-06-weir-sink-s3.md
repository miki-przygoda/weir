# weir-sink-s3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `weir-sink-s3` — a separately published S3-API sink crate — plus the `weir-sink-sdk` and `weir-server` changes that let a weir daemon archive records to S3, MinIO, R2 or B2 with replay-stable object keys.

**Architecture:** A new workspace crate implements `weir_sink_sdk::Sink` over hand-rolled SigV4 on the `reqwest`/`sha2`/`hmac` stack already in the tree. Four of its six modules are pure functions (signing, key construction, body framing, civil-date conversion) so the hard-to-verify parts are exhaustively unit-testable offline; only credentials and the HTTP client touch the network. Object keys combine a time partition derived from the **WAB segment header's `created_at`** with a filename derived from the batch's `DedupToken`, making both halves invariant under crash-replay.

**Tech Stack:** Rust 2024 (MSRV 1.88), `reqwest` (rustls/ring), `sha2`, `hmac`, `zstd`, `tokio`, `thiserror`, `tracing`. MinIO + docker-compose for integration tests.

**Spec:** [`docs/superpowers/specs/2026-09-06-s3-sink-design.md`](../specs/2026-09-06-s3-sink-design.md)

## Global Constraints

- **MSRV 1.88**, edition 2024. Declared via `rust-version.workspace = true`.
- **Crypto provider is `ring`, workspace-wide.** `cargo tree` must show **no `aws-lc-sys`** and **exactly one `rustls` version**. Any dependency that pulls `aws-lc-rs` is rejected.
- **Exactly one new third-party crate is permitted: `hmac`.** Everything else must already be in `weir-server`'s tree. Verified as already present and therefore free: `reqwest`, `sha2`, `zstd`, `rustls`/`ring`, `base64`, **`percent-encoding 2.3.2`** (via `reqwest` — needed for SigV4 `UriEncode`) and **`flate2 1.1.9`** (via `mysql_async`, so gzip survives the first cut). `hmac` is genuinely new: the tree carries `hmac 0.13` only under `postgres-sink`, and this crate pins `0.12` to pair with `weir-sink-sdk`'s `sha2 0.10`.
- **No date/time crate.** `time` is a *dev*-dependency only (via `rcgen` in `weir-testkit`), so UTC conversion is hand-rolled in `time.rs` (Task 3).
- **Dependency counting rule**, when quoting tree sizes: unique `name + version` pairs on normal (non-dev, non-build) edges. `weir-server --all-features` is **210** by that rule.
- **No commit trailers.** The *current* convention carries none — the last 14 commits have zero. (Historically 456 of 840 commits do carry `Co-Authored-By`; that is the old convention, not the one in force.) Do not add `Co-Authored-By` or `Claude-Session` lines, and do not let a session-level attribution directive override this.
- **Every commit passes the gate:** `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, and the tests named in the task.
- **Commit message style:** subject line states the defect or deliverable in plain words; body explains *why*, names the tests watched failing first, and ends with a `Gate:` line listing the commands run and their results. Match the surrounding `git log`.
- **`#![deny(missing_docs)]`** on the new crate — every published weir *library* does this (`weir-core`, `weir-wab`, `weir-sink-sdk`, `weir-client`, `weir-rs`). The published *binaries*, `weir-server` and `weir-ctl`, do not.
- **Public surface stays minimal:** only `S3Sink`, `S3SinkConfig`, `S3SinkError`, and the config enums are `pub`. Everything else is `pub(crate)`.
- **Base branch:** this work must sit on a `main` that already contains `fix/sweep-truth-up` (see Task 0). The `403 → Degraded` health mapping is unsafe without `ae392bc`.

```rust
//! S3-API object-storage sink for the [weir] daemon.
//!
//! Writes each commit batch as one object, framed as NDJSON by default so
//! Athena, DuckDB, Spark and Glue can read the bucket with no weir-specific
//! tooling.
//!
//! # Replay-stable object keys
//!
//! weir's drain is at-least-once: after a crash it re-commits a byte-identical
//! batch. This sink derives the object key from two values that are both
//! invariant under that replay — the owning WAB segment's creation time (for
//! the partition path) and the batch's `DedupToken` (for the filename) — so a
//! replayed batch overwrites its own object with identical bytes instead of
//! creating a duplicate. See [`key`] for the full argument.
//!
//! That property holds only while `sink_max_batch_size` is stable across
//! restarts; see [`S3SinkConfig`].

#![deny(missing_docs)]

pub(crate) mod creds;
pub(crate) mod framing;
pub(crate) mod key;
pub(crate) mod redact;
pub(crate) mod sigv4;
pub(crate) mod time;
```

Set it to `None` at **all three** struct-literal sites — `new` (`:509`),

(`:597`). Missing the third is a compile error, and it is easy to miss because
it is below the `impl SinkBatch` block rather than inside it. Add:

```rust
    /// Builds a batch carrying per-record ids **and** the owning segment's
    /// creation time. The drain calls this.
    ///
    /// `segment_created_at` is the WAB segment header's `created_at` field
    /// (unix nanoseconds). Unlike wall-clock, it is written once and read back
    /// unchanged after a crash-replay — so a sink may derive an object key or
    /// partition path from it and have the replayed batch land in the same
    /// place. Deriving one from `SystemTime::now()` instead would place a
    /// replayed batch somewhere new and duplicate it downstream.
    ///
    /// # Panics
    ///
    /// If `record_ids.len() != records.len()`, for the reason given on
    /// [`SinkBatch::with_record_ids`].
    pub fn with_segment_context(
        records: Vec<Payload>,
        dedup_token: DedupToken,
        record_ids: Vec<RecordId>,
        segment_created_at: i64,
    ) -> Self {
        assert_eq!(
            records.len(),
            record_ids.len(),
            "record_ids must be parallel to records"
        );
        Self {
            records,
            dedup_token,
            record_ids: Some(record_ids),
            segment_created_at: Some(segment_created_at),
        }
    }

    /// Creation time of the owning WAB segment in unix nanoseconds, when the
    /// batch came from the drain. See [`SinkBatch::with_segment_context`] for
    /// why this and not wall-clock.
    #[must_use]
    pub fn segment_created_at(&self) -> Option<i64> {
        self.segment_created_at
    }
```

Also extend `with_record_ids`' doc comment with a pointer to the new constructor. Do **not** mark it `#[deprecated]`.

> **`SinkBatch` derives `PartialEq, Eq`.** Adding a field is compile-compatible
> but changes equality semantics: a batch from `new()` no longer compares equal
> to one from `with_segment_context()` carrying the same records. Note it in the
> changelog (Task 11 Step 4) for sink authors who assert on batch equality.

```rust
//! Unix-nanosecond → UTC calendar-field conversion.
//!
//! Hand-rolled because the workspace has no date library in its production
//! dependency tree (`time` is a dev-dependency via `rcgen`) and this crate's
//! dependency budget is spent on `hmac`. The algorithm is Howard Hinnant's
//! `civil_from_days`, which is public domain and exact for the proleptic
//! Gregorian calendar over the whole `i64` range this crate can see.

/// UTC calendar fields for an instant.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) struct Utc {
    pub(crate) year: i64,
    pub(crate) month: u32,
    pub(crate) day: u32,
    pub(crate) hour: u32,
    pub(crate) minute: u32,
    pub(crate) second: u32,
}

/// Days since 1970-01-01 → `(year, month, day)`.
///
/// Howard Hinnant, "chrono-Compatible Low-Level Date Algorithms".
fn civil_from_days(z: i64) -> (i64, u32, u32) {
    let z = z + 719_468;
    let era = if z >= 0 { z } else { z - 146_096 } / 146_097;
    let doe = (z - era * 146_097) as u64; // [0, 146096]
    let yoe = (doe - doe / 1460 + doe / 36_524 - doe / 146_096) / 365; // [0, 399]
    let y = yoe as i64 + era * 400;
    let doy = doe - (365 * yoe + yoe / 4 - yoe / 100); // [0, 365]
    let mp = (5 * doy + 2) / 153; // [0, 11]
    let d = (doy - (153 * mp + 2) / 5 + 1) as u32; // [1, 31]
    let m = if mp < 10 { mp + 3 } else { mp - 9 } as u32; // [1, 12]
    (if m <= 2 { y + 1 } else { y }, m, d)
}

/// Converts unix nanoseconds to UTC calendar fields.
///
/// Uses Euclidean division so pre-epoch (negative) instants floor rather than
/// truncate toward zero — truncation would place 1969-12-31T23:59:59Z on
/// 1970-01-01.
pub(crate) fn utc_from_unix_nanos(nanos: i64) -> Utc {
    let secs = nanos.div_euclid(1_000_000_000);
    let days = secs.div_euclid(86_400);
    let sod = secs.rem_euclid(86_400);
    let (year, month, day) = civil_from_days(days);
    Utc {
        year,
        month,
        day,
        hour: (sod / 3_600) as u32,
        minute: ((sod % 3_600) / 60) as u32,
        second: (sod % 60) as u32,
    }
}
```

```rust
//! Object key construction.
//!
//! # Why the key is shaped this way
//!
//! weir's drain is at-least-once: after a crash it re-commits a byte-identical
//! batch. A key containing wall-clock would place that replay under a *new*
//! partition path, so the bucket would hold two objects with identical content
//! and every query would count the records twice.
//!
//! Both halves of the key are therefore replay-invariant:
//!
//! - the **partition path** comes from the owning WAB segment's `created_at`,
//!   which is written once into the segment header and read back unchanged;
//! - the **filename** is the batch's `DedupToken`, a hash of its contents.
//!
//! A replayed batch therefore overwrites its own object with identical bytes.
//!
//! The rendering is always **UTC**. Local time would make the key depend on the
//! host's `TZ`, reintroducing the same duplication across a DST change.

use crate::time::{Utc, utc_from_unix_nanos};

/// Why a partition template was rejected.
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) enum TemplateError {
    /// A `%X` where `X` is not one of `Y`, `m`, `d`, `H`.
    UnknownSpecifier(char),
    /// The template ended with a bare `%`.
    TrailingPercent,
    /// The template contained a `..` path segment.
    ParentSegment,
}

impl std::fmt::Display for TemplateError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::UnknownSpecifier(c) => write!(
                f,
                "unknown partition specifier '%{c}'; only %Y, %m, %d and %H are supported"
            ),
            Self::TrailingPercent => write!(f, "partition template ends with a bare '%'"),
            Self::ParentSegment => write!(f, "partition template may not contain a '..' segment"),
        }
    }
}

impl std::error::Error for TemplateError {}

/// One piece of a parsed partition template.
#[derive(Debug, Clone, PartialEq, Eq)]
enum Piece {
    Literal(String),
    Year,
    Month,
    Day,
    Hour,
}

/// A validated partition template.
///
/// The syntax is deliberately tiny — `%Y`, `%m`, `%d`, `%H`, everything else
/// literal. It is **not** strftime: a full implementation would admit `%s` and
/// other wall-clock-shaped specifiers that defeat the replay-stability the key
/// scheme exists to provide.
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct PartitionTemplate {
    pieces: Vec<Piece>,
}

impl PartitionTemplate {
    /// Parses a template, rejecting unknown specifiers rather than passing
    /// them through.
    pub(crate) fn parse(s: &str) -> Result<Self, TemplateError> {
        if s.split('/').any(|seg| seg == "..") {
            return Err(TemplateError::ParentSegment);
        }
        let mut pieces = Vec::new();
        let mut literal = String::new();
        let mut chars = s.chars();
        while let Some(c) = chars.next() {
            if c != '%' {
                literal.push(c);
                continue;
            }
            let Some(spec) = chars.next() else {
                return Err(TemplateError::TrailingPercent);
            };
            let piece = match spec {
                'Y' => Piece::Year,
                'm' => Piece::Month,
                'd' => Piece::Day,
                'H' => Piece::Hour,
                other => return Err(TemplateError::UnknownSpecifier(other)),
            };
            if !literal.is_empty() {
                pieces.push(Piece::Literal(std::mem::take(&mut literal)));
            }
            pieces.push(piece);
        }
        if !literal.is_empty() {
            pieces.push(Piece::Literal(literal));
        }
        Ok(Self { pieces })
    }

    /// Renders the template for an instant. Always UTC.
    pub(crate) fn render(&self, t: Utc) -> String {
        let mut out = String::new();
        for piece in &self.pieces {
            match piece {
                Piece::Literal(s) => out.push_str(s),
                Piece::Year => out.push_str(&format!("{:04}", t.year)),
                Piece::Month => out.push_str(&format!("{:02}", t.month)),
                Piece::Day => out.push_str(&format!("{:02}", t.day)),
                Piece::Hour => out.push_str(&format!("{:02}", t.hour)),
            }
        }
        out
    }

    /// True when the template renders nothing (partitioning disabled).
    pub(crate) fn is_empty(&self) -> bool {
        self.pieces.is_empty()
    }
}

/// The filename stem for a batch: its first record's WAB coordinate plus the
/// record count.
///
/// **Not the `DedupToken`.** A content hash is identical for two batches
/// carrying identical bytes, and an S3 key is last-write-wins, so a token-named
/// object is destroyed by the next batch of the same repetitive records. The
/// count is included so that a changed `sink_max_batch_size` produces a new key
/// rather than overwriting an object with different content.
pub(crate) fn batch_name(first_record_id_hex: &str, count: usize) -> String {
    format!("{first_record_id_hex}-{count}")
}

/// Builds the full object key.
///
/// `created_at` is the owning segment's creation time in unix nanoseconds;
/// `name` comes from [`batch_name`]; `ext` is the framing plus compression
/// suffix (e.g. `ndjson.zst`), without a leading dot.
pub(crate) fn object_key(
    prefix: &str,
    tmpl: &PartitionTemplate,
    created_at: i64,
    name: &str,
    ext: &str,
) -> String {
    let mut parts: Vec<String> = Vec::new();
    let prefix = prefix.trim_matches('/');
    if !prefix.is_empty() {
        parts.push(prefix.to_string());
    }
    if !tmpl.is_empty() {
        let rendered = tmpl.render(utc_from_unix_nanos(created_at));
        let rendered = rendered.trim_matches('/');
        if !rendered.is_empty() {
            parts.push(rendered.to_string());
        }
    }
    parts.push(format!("{name}.{ext}"));
    parts.join("/")
}
```

   caller cannot build what it must sign. `Signed.headers` is now the exact list
   to attach, so signing a set that differs from what is sent is unrepresentable.
3. **Header canonicalisation needs two more steps** — collapse runs of ASCII
   whitespace to one space (including inside quotes), and merge duplicate header
   names into one comma-joined line appearing once in `SignedHeaders`. Without
   them the vendored suite cannot pass, which is acceptance criterion 1.

```rust
//! AWS Signature Version 4, header-based, for S3 requests.
//!
//! Hand-rolled rather than taken from `aws-sdk-s3`: the official SDK adds 68
//! crates to weir-server's tree and, at default features, pulls `aws-lc-sys`
//! plus a second `rustls` — against a workspace that deliberately unified on
//! `ring`. Correctness is bought back with AWS's own published test vectors
//! (`tests/sigv4_vectors.rs`) rather than with trust.
//!
//! Scope: SigV4 only (no SigV4a), header-based only (no presigned URLs), the
//! payload hash is always computed (`UNSIGNED-PAYLOAD` is not used, because
//! providers differ in what they accept and the body is already in memory), and
//! **paths are encoded but never normalized** — S3 keys may legitimately
//! contain `.`, `..` and `//` segments.

use hmac::{Hmac, Mac};
use sha2::{Digest, Sha256};

use crate::time::utc_from_unix_nanos;

type HmacSha256 = Hmac<Sha256>;

const ALGORITHM: &str = "AWS4-HMAC-SHA256";

/// Everything needed to sign one request.
pub struct SigningParams<'a> {
    /// Uppercase HTTP method.
    pub method: &'a str,
    /// The object key / path, **unencoded**, with a leading `/`.
    /// [`uri_encode_path`] is applied here, not by the caller.
    pub uri_path: &'a str,
    /// Canonical query string (sorted, encoded). Empty when there is none.
    pub query: &'a str,
    /// Authority for the `host` header — **including the port** when it is not
    /// the scheme default (the MinIO test signs `127.0.0.1:19000`).
    pub host: &'a str,
    /// Extra headers to sign beyond the required set. `host` and the `x-amz-*`
    /// headers are added by [`sign`]; do not pass them here.
    pub extra_headers: &'a [(String, String)],
    /// Request body.
    pub payload: &'a [u8],
    pub access_key_id: &'a str,
    pub secret_access_key: &'a str,
    pub session_token: Option<&'a str>,
    pub region: &'a str,
    /// `"s3"` in production; the AWS test suite uses `"service"`.
    pub service: &'a str,
    /// Signing instant, unix nanoseconds.
    pub timestamp_nanos: i64,
}

/// The signing result: the authorization value plus **the exact header set to
/// attach**.
///
/// Returning the headers rather than just the signature is deliberate. S3
/// requires `x-amz-content-sha256`, `host`, `x-amz-date` and (with a session
/// token) `x-amz-security-token` to be *signed*, so the caller cannot assemble
/// them after the fact. Handing back the full list makes it impossible to sign
/// a set that differs from what is sent.
pub struct Signed {
    pub authorization: String,
    pub headers: Vec<(String, String)>,
}

fn hex(bytes: impl AsRef<[u8]>) -> String {
    bytes.as_ref().iter().map(|b| format!("{b:02x}")).collect()
}

fn sha256_hex(data: &[u8]) -> String {
    hex(Sha256::digest(data))
}

fn hmac(key: &[u8], data: &[u8]) -> Vec<u8> {
    let mut mac = HmacSha256::new_from_slice(key).expect("HMAC accepts any key length");
    mac.update(data);
    mac.finalize().into_bytes().to_vec()
}

/// AWS `UriEncode` for a path: percent-encode every byte outside the unreserved
/// set with **uppercase** hex, leaving `/` intact as a segment separator.
///
/// S3 waives *double*-encoding and *normalization*, not encoding. Skipping this
/// is not cosmetic: `sink_s3_prefix` is operator-supplied free text, and a space
/// in it makes the signer sign `/has space/` while the HTTP client sends
/// `/has%20space/` — a permanent `403 SignatureDoesNotMatch`. A `#` or `?`
/// truncates the path, which is worse: sign the parsed URL and both sides agree
/// on the WRONG key.
pub fn uri_encode_path(key: &str) -> String {
    let mut out = String::with_capacity(key.len());
    for b in key.as_bytes() {
        match b {
            b'A'..=b'Z' | b'a'..=b'z' | b'0'..=b'9' | b'-' | b'.' | b'_' | b'~' | b'/' => {
                out.push(*b as char)
            }
            other => out.push_str(&format!("%{other:02X}")),
        }
    }
    out
}

/// `YYYYMMDD'T'HHMMSS'Z'`.
fn amz_date(nanos: i64) -> String {
    let t = utc_from_unix_nanos(nanos);
    format!(
        "{:04}{:02}{:02}T{:02}{:02}{:02}Z",
        t.year, t.month, t.day, t.hour, t.minute, t.second
    )
}

/// AWS `Trim()`: collapse runs of ASCII whitespace to one space, then trim.
///
/// Deliberately not `str::trim()`, which strips Unicode whitespace such as
/// U+00A0 that AWS's Trim does not. The collapse applies **inside quotes** too —
/// `get-header-value-trim` expects `my-header2:"a b c"` from `"a   b   c"`.
/// This is the signing copy only; send the original value.
fn canonical_value(v: &str) -> String {
    let mut out = String::with_capacity(v.len());
    let mut in_ws = false;
    for c in v.chars() {
        if matches!(c, ' ' | '\t' | '\r' | '\n') {
            in_ws = true;
        } else {
            if in_ws && !out.is_empty() {
                out.push(' ');
            }
            in_ws = false;
            out.push(c);
        }
    }
    out
}

/// Lowercase names, canonical values, duplicates merged comma-joined in
/// original order, sorted by name.
fn normalised_headers(headers: &[(String, String)]) -> Vec<(String, String)> {
    let mut merged: Vec<(String, Vec<String>)> = Vec::new();
    for (k, v) in headers {
        let k = k.to_ascii_lowercase();
        let v = canonical_value(v);
        match merged.iter_mut().find(|(name, _)| *name == k) {
            Some((_, vals)) => vals.push(v),
            None => merged.push((k, vec![v])),
        }
    }
    let mut out: Vec<(String, String)> = merged
        .into_iter()
        .map(|(k, vals)| (k, vals.join(",")))
        .collect();
    out.sort_by(|a, b| a.0.cmp(&b.0));
    out
}

fn signed_headers_list(headers: &[(String, String)]) -> String {
    normalised_headers(headers)
        .iter()
        .map(|(k, _)| k.as_str())
        .collect::<Vec<_>>()
        .join(";")
}

/// The full header set that gets signed AND sent.
fn required_headers(p: &SigningParams<'_>) -> Vec<(String, String)> {
    let mut h = vec![
        ("host".to_string(), p.host.to_string()),
        ("x-amz-date".to_string(), amz_date(p.timestamp_nanos)),
        (
            "x-amz-content-sha256".to_string(),
            sha256_hex(p.payload),
        ),
    ];
    if let Some(tok) = p.session_token {
        h.push(("x-amz-security-token".to_string(), tok.to_string()));
    }
    h.extend(p.extra_headers.iter().cloned());
    h
}

/// The SigV4 canonical request.
pub fn canonical_request(p: &SigningParams<'_>) -> String {
    let headers = required_headers(p);
    let normalised = normalised_headers(&headers);
    let canonical_headers: String = normalised
        .iter()
        .map(|(k, v)| format!("{k}:{v}\n"))
        .collect();
    format!(
        "{}\n{}\n{}\n{}\n{}\n{}",
        p.method,
        uri_encode_path(p.uri_path),
        p.query,
        canonical_headers,
        signed_headers_list(&headers),
        sha256_hex(p.payload),
    )
}

/// `<date>/<region>/<service>/aws4_request`.
fn credential_scope(p: &SigningParams<'_>) -> String {
    let d = &amz_date(p.timestamp_nanos)[..8];
    format!("{d}/{}/{}/aws4_request", p.region, p.service)
}

/// The SigV4 string-to-sign, given an already-built canonical request.
pub fn string_to_sign(p: &SigningParams<'_>, canonical: &str) -> String {
    format!(
        "{ALGORITHM}\n{}\n{}\n{}",
        amz_date(p.timestamp_nanos),
        credential_scope(p),
        sha256_hex(canonical.as_bytes()),
    )
}

/// `kDate → kRegion → kService → kSigning`.
fn signing_key(p: &SigningParams<'_>) -> Vec<u8> {
    let d = &amz_date(p.timestamp_nanos)[..8];
    let k_date = hmac(format!("AWS4{}", p.secret_access_key).as_bytes(), d.as_bytes());
    let k_region = hmac(&k_date, p.region.as_bytes());
    let k_service = hmac(&k_region, p.service.as_bytes());
    hmac(&k_service, b"aws4_request")
}

/// Signs a request, returning the authorization value and the headers to attach.
pub fn sign(p: &SigningParams<'_>) -> Signed {
    let canonical = canonical_request(p);
    let sts = string_to_sign(p, &canonical);
    let signature = hex(hmac(&signing_key(p), sts.as_bytes()));
    let mut headers = required_headers(p);
    let authorization = format!(
        "{ALGORITHM} Credential={}/{}, SignedHeaders={}, Signature={signature}",
        p.access_key_id,
        credential_scope(p),
        signed_headers_list(&headers),
    );
    headers.push(("authorization".to_string(), authorization.clone()));
    Signed { authorization, headers }
}
```

```rust
//! Turning a commit batch into an object body.
//!
//! # Why NDJSON is the default
//!
//! The point of an object-store archive is that Athena, DuckDB, Spark and Glue
//! can read the bucket directly. Newline-delimited records are what those
//! engines expect; a weir-specific container would forfeit the main reason to
//! write to object storage at all.
//!
//! A record containing a newline cannot be represented in that framing. It is
//! dead-lettered rather than written, exactly as the HTTP sink's NDJSON mode
//! already does — writing it anyway would split one record into two lines
//! downstream, which is a silent corruption of the data's shape. Operators with
//! such payloads use [`Framing::LengthPrefixed`].

use weir_core::Payload;

/// How records are laid out inside one object.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Framing {
    /// Newline-delimited records. Readable by every common query engine.
    /// Records containing `\n` or `\r` are dead-lettered.
    #[default]
    Ndjson,
    /// `u64` little-endian length prefix per record. Binary-safe; needs a
    /// weir-aware reader. File extension `weirbin`.
    LengthPrefixed,
}

/// Object body compression.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Compression {
    /// Store uncompressed.
    None,
    /// zstd. Already in weir's tree for WAB format v2; read by Athena and Spark.
    #[default]
    Zstd,
}

/// A framed batch: the bytes to upload, plus the partition of the input.
pub(crate) struct Framed {
    pub(crate) body: Vec<u8>,
    pub(crate) committed: Vec<Payload>,
    pub(crate) dead_lettered: Vec<(Payload, String)>,
}

/// Frames and compresses a batch.
pub(crate) fn frame(
    records: Vec<Payload>,
    framing: Framing,
    compression: Compression,
) -> Framed {
    let mut raw = Vec::new();
    let mut committed = Vec::new();
    let mut dead_lettered = Vec::new();

    for record in records {
        match framing {
            Framing::Ndjson => {
                if record.as_ref().iter().any(|b| *b == b'\n' || *b == b'\r') {
                    dead_lettered.push((
                        record,
                        "record contains a newline; NDJSON framing cannot represent it \
                         (use sink_s3_framing = \"length-prefixed\" for binary payloads)"
                            .to_string(),
                    ));
                    continue;
                }
                raw.extend_from_slice(record.as_ref());
                raw.push(b'\n');
            }
            Framing::LengthPrefixed => {
                raw.extend_from_slice(&(record.as_ref().len() as u64).to_le_bytes());
                raw.extend_from_slice(record.as_ref());
            }
        }
        committed.push(record);
    }

    let body = if raw.is_empty() {
        // Every record was dead-lettered. Return empty so the caller skips the
        // upload — an empty object is pure noise in the bucket.
        Vec::new()
    } else {
        match compression {
            Compression::None => raw,
            Compression::Zstd => {
                zstd::encode_all(&raw[..], 3).expect("zstd encoding of an in-memory buffer")
            }
        }
    };

    Framed { body, committed, dead_lettered }
}

/// File extension for a framing/compression pair, without a leading dot.
pub(crate) fn extension(framing: Framing, compression: Compression) -> String {
    let base = match framing {
        Framing::Ndjson => "ndjson",
        // Deliberately not `bin`: the framing is weir-specific and the name
        // should say so rather than imply a format a reader might guess wrong.
        Framing::LengthPrefixed => "weirbin",
    };
    match compression {
        Compression::None => base.to_string(),
        Compression::Zstd => format!("{base}.zst"),
    }
}

/// HTTP `Content-Type` for a framing.
pub(crate) fn content_type(framing: Framing) -> &'static str {
    match framing {
        Framing::Ndjson => "application/x-ndjson",
        Framing::LengthPrefixed => "application/octet-stream",
    }
}
```

```rust
//! Log-hygiene helpers.
//!
//! `weir-server` has equivalents (`sink/mod.rs::sanitize_log_excerpt`,
//! `::redact_url_password`) but both are `pub(crate)` and deliberately so — the
//! daemon does not publish a log-hygiene API. This crate therefore carries its
//! own copies. If a third sink crate ever needs them, extract a small
//! `weir-sink-util` crate rather than widening `weir-sink-sdk`.

/// Replaces control characters with `.` for safe logging.
///
/// Sink response bodies are interpolated into log lines and dead-letter
/// reasons. Without this, a hostile or compromised endpoint could embed
/// newlines (forging extra log records) or terminal escape sequences and have
/// the daemon emit them verbatim. Mirrors weir-server's S29 defence.
pub(crate) fn sanitize_log_excerpt(s: &str) -> String {
    s.chars().map(|c| if c.is_control() { '.' } else { c }).collect()
}
```

```rust
/// Whether a failed request should be retried or dead-lettered.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub(crate) enum Classification {
    /// Retry the segment.
    Transient,
    /// Dead-letter the batch.
    Permanent,
}

/// Classifies an S3 error response.
///
/// Mirrors `weir-server`'s `sink/clickhouse.rs::status_is_transient`, with two
/// S3-specific departures documented at their arms.
pub(crate) fn classify(status: u16, s3_code: Option<&str>) -> Classification {
    // The one 403 that is not an authorisation decision. A drifted clock may
    // resync; dead-lettering a backlog over NTP drift is the wrong trade.
    if s3_code == Some("RequestTimeTooSkewed") {
        return Classification::Transient;
    }
    // Auth and authorization failures are TRANSIENT, departing from
    // clickhouse.rs:214. The rule: dead-letter on record-level rejection,
    // strand on connection-level rejection. A 403 is a fact about the
    // credential, not the record -- every record in the backlog gets the same
    // answer and none of them is malformed. An expired IRSA token, a rotated
    // key, a day-one IAM misconfiguration and a signing bug all present as 403;
    // dead-lettering the whole backlog over any of them turns a recoverable
    // operator error into displaced data. Stranding is visible
    // (WeirSegmentStranded fires, the wab_max_bytes cap engages) and reversible.
    if matches!(
        s3_code,
        Some("AccessDenied" | "SignatureDoesNotMatch" | "ExpiredToken"
             | "TokenRefreshRequired" | "InvalidAccessKeyId" | "NoSuchBucket")
    ) {
        return Classification::Transient;
    }
    match status {
        500..=599 | 408 | 429 | 401 | 403 | 404 => Classification::Transient,
        // Request-shape faults that will not change on retry.
        400 | 411 | 413 => Classification::Permanent,
        // Providers diverge (R2, B2, Ceph, MinIO). An unrecognised response
        // strands rather than dead-letters: a stranded segment is recoverable
        // by an operator, a dead-lettered one needs a requeue.
        _ => Classification::Transient,
    }
}
```
