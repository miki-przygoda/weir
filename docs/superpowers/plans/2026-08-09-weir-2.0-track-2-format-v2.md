# weir 2.0 Track 2 — WAB format v2 and transparent zstd compression

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add WAB segment format v2 — header byte `[5]` becomes a flags byte —
and opt-in per-record zstd compression, so a WAB absorbs proportionally longer
sink outages in the same disk budget.

**Architecture:** Read side first, write side second, so no segment is ever
written that the tree cannot read. The per-record CRC keeps covering the
**stored** bytes, which means recovery, `verify_sealed_segment`, and the footer
cross-check need no compression awareness at all — decompression happens in
exactly one place, `SegmentReader::next`, after the CRC has passed. The codec
lives in `ShardWriter`, **above** the `SegmentStore`/`SegmentHandle` seam, so the
DST harness drives real compressed byte streams through its fault schedules.

**Tech Stack:** Rust 2024, the `zstd` crate (`zstd::bulk`), `weir-wab`,
`weir-server`.

with:

```rust
/// Format v1: the original layout. Header byte `[5]` is reserved and MUST be
/// zero.
pub const FORMAT_VERSION_V1: u8 = 1;

/// Format v2: identical to v1 except header byte `[5]` is a flags byte. Record
/// framing, the sentinel, the footer, and the `.confirmed` sidecar are
/// byte-for-byte unchanged.
pub const FORMAT_VERSION_V2: u8 = 2;

/// The highest version this build can *read*. Deliberately not "the version we
/// write": the writer picks the lowest version that can express the segment's
/// features (v1 when compression is off, v2 when it is on), so that value is a
/// function of config, not a constant.
pub const FORMAT_VERSION_MAX_SUPPORTED: u8 = FORMAT_VERSION_V2;

/// Header flags bit 0 — every record in this segment is stored as a zstd frame.
pub const FLAG_ZSTD: u8 = 0b0000_0001;

/// Mask of every flags bit this build understands. A set bit outside it means
/// the segment was written by a newer weir, and reading it would misinterpret
/// the records — so the parse refuses.
const KNOWN_FLAGS: u8 = FLAG_ZSTD;

/// How a segment's records are stored on disk. Carried in header byte `[5]`.
///
/// Segment-scoped, not per-record: the record framing has no spare bit, and
/// compression is a deployment setting rather than a per-record decision.
#[derive(Debug, Clone, Copy, PartialEq, Eq, Default)]
pub enum Compression {
    /// Records are stored verbatim. Written as a v1 header.
    #[default]
    None,
    /// Every record is a complete zstd frame. Written as a v2 header with
    /// [`FLAG_ZSTD`] set.
    Zstd,
}

impl Compression {
    /// The header flags byte for this mode.
    pub fn flags(self) -> u8 {
        match self {
            Compression::None => 0,
            Compression::Zstd => FLAG_ZSTD,
        }
    }

    /// The lowest format version that can express this mode. v1 has no flags
    /// byte, so anything other than `None` needs v2 — this is what makes
    /// "upgrade with compression off, then roll back" a non-event.
    pub fn format_version(self) -> u8 {
        match self {
            Compression::None => FORMAT_VERSION_V1,
            Compression::Zstd => FORMAT_VERSION_V2,
        }
    }
}
```

    let flags = buf[5];
    let compression = match buf[4] {
        // v1 predates the flags byte and documented it as zero-on-write, so a
        // set bit is corruption, not a feature.
        FORMAT_VERSION_V1 if flags == 0 => Compression::None,
        FORMAT_VERSION_V1 => {
            return Err(SegmentHeaderParseError::ReservedFlagsSet {
                version: FORMAT_VERSION_V1,
                flags,
            });
        }
        // v2: refuse any bit we do not understand rather than read the records
        // under the wrong assumption.
        FORMAT_VERSION_V2 if flags & !KNOWN_FLAGS != 0 => {
            return Err(SegmentHeaderParseError::ReservedFlagsSet {
                version: FORMAT_VERSION_V2,
                flags,
            });
        }
        FORMAT_VERSION_V2 if flags & FLAG_ZSTD != 0 => Compression::Zstd,
        FORMAT_VERSION_V2 => Compression::None,
        other => return Err(SegmentHeaderParseError::UnknownVersion(other)),
    };
    Ok(SegmentHeaderMeta {
        format_version: buf[4],
        compression,
        shard_id: u16::from_le_bytes(buf[6..8].try_into().unwrap()),
        created_at: i64::from_le_bytes(buf[8..16].try_into().unwrap()),

    // ── v2 / compressed segments ──────────────────────────────────────────────

    /// Writes a segment by hand at a chosen compression, so the reader can be
    /// tested before any production code writes v2.
    fn write_v2_segment(path: &std::path::Path, compression: Compression, records: &[&[u8]]) {
        use std::io::Write as _;
        let mut f = std::fs::File::create(path).unwrap();
        f.write_all(&build_segment_header(0, compression)).unwrap();
        let mut data_bytes = 0u64;
        let mut hasher = crc32fast::Hasher::new();
        hasher.update(&build_segment_header(0, compression));
        for r in records {
            let stored = match compression {
                Compression::None => r.to_vec(),
                Compression::Zstd => zstd::bulk::compress(r, 1).unwrap(),
            };
            let len = (stored.len() as u32).to_le_bytes();
            let crc = crc32fast::hash(&stored).to_le_bytes();
            f.write_all(&len).unwrap();
            f.write_all(&crc).unwrap();
            f.write_all(&stored).unwrap();
            hasher.update(&len);
            hasher.update(&crc);
            hasher.update(&stored);
            data_bytes += stored.len() as u64;
        }
        let file_crc32 = hasher.finalize();
        f.write_all(&build_sentinel()).unwrap();
        f.write_all(&build_segment_footer(
            records.len() as u64,
            data_bytes,
            file_crc32,
            0,
        ))
        .unwrap();
    }

- [ ] **Step 4: Add the bound helper**

In `crates/weir-wab/src/format.rs`:

```rust
/// zstd's worst-case compressed size for `n` input bytes: `n + n/255 + 16`.
///
/// Spelled out here rather than taken from the zstd crate so the on-disk
/// contract does not move if the dependency does — this value bounds what a
/// reader will accept, and it must be stable across builds.
pub const fn compress_bound(n: usize) -> usize {
    n + n / 255 + 16
}

/// The largest `payload_len` a **v2 ZSTD** segment may legitimately declare.
///
/// A maximal incompressible payload stores larger than it started, so the v1 cap
/// of `MAX_PAYLOAD_HARD_CAP` would reject a valid record. The plaintext is still
/// capped at `MAX_PAYLOAD_HARD_CAP` — enforced on the decompression *output*,
/// which is also the decompression-bomb guard.

        // payload compresses to a ~9-byte frame that writes and reads back

        // WAB's own boundary check.

        // here returns before anything is written and before any accounting

                    io::Error::other(format!("failed to compress a WAB record: {e}"))
                })?,
            ),
        };

        let got: Vec<_> = weir_wab::SegmentReader::open(&sealed_path_for(&seg))
            .unwrap()
            .map(|r| r.unwrap())
            .collect();
        assert_eq!(got.len(), 2, "the torn third record must be dropped");
        assert_eq!(got[0].as_ref(), b"one");
        assert_eq!(got[1].as_ref(), b"two");
        std::fs::remove_dir_all(dir).ok();
    }

    #[test]
    fn recovery_preserves_the_compression_flag() {
        // Recovery finalises an existing file, so the header it was created with
        // must still be there afterwards. If this ever fails, a recovered
        // segment becomes unreadable — its records are frames but its header
        // says they are not.
        let dir = tmp_dir("v2_flag_preserved");
        let seg = write_compressed_active_segment(&dir, &[b"one"]);
        recover_segment(&seg, &noop_metrics()).unwrap();

        let meta =
            weir_wab::parse_segment_header(&read_header(&sealed_path_for(&seg))).unwrap();
        assert_eq!(meta.compression, Compression::Zstd);
        std::fs::remove_dir_all(dir).ok();
    }

    #[test]
    fn mid_file_corruption_in_a_compressed_segment_quarantines() {
        // The 1.1.0 behaviour must hold under compression: a CRC mismatch in the
        // MIDDLE of a recovered active segment quarantines rather than
        // truncating, so acked records after the corruption are preserved.
        let dir = tmp_dir("v2_midfile");
        let seg = write_compressed_active_segment(&dir, &[b"one", b"two", b"three"]);
        flip_a_byte_in_the_second_record(&seg);

        let _ = recover_segment(&seg, &noop_metrics());
        assert!(
            dir.join("quarantine").read_dir().unwrap().next().is_some(),
            "a mid-file-corrupt compressed segment must be quarantined"
        );
        std::fs::remove_dir_all(dir).ok();
    }
```

- **WAB format v2 and opt-in zstd compression.** Header byte `[5]`, reserved and
  zero since v1, becomes a flags byte; bit 0 means every record in the segment is

  one place.
